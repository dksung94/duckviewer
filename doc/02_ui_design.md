## 1. 화면 구성

```
┌──────────┬───────────────────────────┬─────────────────┐
│ 사이드바  │ 툴바: 페이지 ▲ 2/6 ▼ · 확대/축소 · 보기 · Claude · 검색 │
│ ┌──────┐ ├───────────────────────────┤ Claude      ⋯   │
│ │썸네일 │ │                           │      [요약 p.2] │
│ │목차   │ │                           │ 답변 (p.2 링크)  │
│ │메모   │ │   PDF (선택 액션 바)       │   [이어서 질문] │
│ │검색   │ │                           │ 답변 …          │
│ └──────┘ │                           ├─────────────────┤
│          │                           │ 범위 · 템플릿    │
│          │                           │ 질문 입력        │
└──────────┴───────────────────────────┴─────────────────┘
```

- **왼쪽 사이드바**: 문서를 탐색하는 곳 (썸네일 / 목차 / 메모 / 검색)
- **가운데**: 읽는 곳. PDF가 세로 전체를 쓴다.
- **오른쪽 패널**: 문서별 Claude 대화. v0.3에서 내장 터미널을 빼고 자체 채팅 UI로 바꿨다. 같은 대화를 터미널에서 이어가려면 ⋯ 메뉴의 "터미널에서 이어하기 명령 복사"를 쓴다.

사이드바(⌃⌘S)와 Claude 패널(⌥⌘0)은 숨길 수 있다.

## 2. 경쟁 제품 패턴과 반영 내용

| 패턴 | 참고한 제품 | DuckViewer에서 |
|---|---|---|
| 왼쪽 사이드바에 썸네일, 목차, 주석 목록을 탭으로 | PDF Expert, Skim | 아이콘 탭 4개. 메모 탭은 페이지순 정렬, 하이라이트 색 막대, 클릭하면 해당 위치로 이동 |
| 목차 항목에 마우스를 올리거나 우클릭해 작업 | Skim | 목차 우클릭으로 **이 장 요약 / 설명 / 번역…**. 장 범위는 다음 같은 단계 항목 직전 페이지까지로 자동 계산 |
| AI는 오른쪽 사이드 패널 | Acrobat AI Assistant, Readwise Ghostreader | 오른쪽 인스펙터 (macOS 표준 `.inspector`) |
| 답변의 출처를 클릭하면 해당 페이지로 이동 | Acrobat | 응답 속 `(p.N)`, `p.N–M`을 링크로 바꿔 클릭하면 이동 |
| 텍스트를 선택하면 작은 메뉴가 뜸 | Readwise Reader, PDF Expert | 드래그를 끝내면 선택 영역 위에 **선택 액션 바**: 하이라이트, 메모, 템플릿 3개, 더보기(나머지 템플릿, AI에게 질문, 터미널로 보내기, 복사) |
| 사용자 정의 프롬프트 | Readwise Ghostreader | 설정의 **프롬프트 템플릿** 편집기. 순서를 바꾸면 액션 바와 단축키에 반영 |
| 범위 단위 요약 (페이지 / 선택 / 범위) | UPDF | AI 패널 아래쪽 범위 선택. 텍스트를 드래그하면 자동으로 "선택 영역"으로 바뀜 |
| 원본을 건드리지 않는 하이라이트와 메모 | Skim, Highlights | 사이드카 JSON에 저장하고 화면에만 주석으로 그림. Markdown 내보내기(⇧⌘E) |
| 시작 화면의 최근 문서 | Preview, PDF Expert | 최근 문서 6개 |
| 읽기 테마 | Readwise, 전자책 리더 | 기본 / 세피아 / 다크 (페이지 색 반전 + 색상 회전으로 하이라이트 색 유지) |

## 3. 일부러 다르게 한 것

- **v0.2의 결과 카드 → v0.3의 문서별 대화.** 처음에는 어떤 AI CLI든 쓰도록 호출마다 독립된 결과 카드로 보여줬다. v0.3에서 Claude 전용으로 바꾸면서 PDF마다 Claude Code 세션을 하나 두고 `--resume`으로 이어가게 했다. 후속 질문이 앞 대화를 기억하고, 문서를 다시 열어도 이어진다. SumatraPDF의 "탭마다 세션" 방식과 같다.
- **텍스트를 넘기되, 필요하면 Claude가 직접 읽는다.** 기본은 범위의 텍스트를 메시지에 붙여 빠르고 싸게 처리한다. 텍스트가 없는 스캔본, 너무 긴 범위, 그림·표가 필요한 질문은 Claude가 `Read` 도구로 PDF를 직접 읽는다. 그래서 별도 OCR 없이 스캔본도 다룬다.
- **추천 질문(Acrobat)은 넣지 않았다.** 추천 질문을 만들려면 Claude를 한 번 더 호출해야 한다. 대신 템플릿 칩을 한 번 눌러 실행하게 했다.
- **내장 터미널은 뺐다 (v0.3).** 같은 세션을 터미널에서 이어가는 명령만 복사해 준다. 현재 읽기 상태는 여전히 `~/.duckviewer/context.json`에 쓴다.

## 4. 각주 메모 (v0.4)

나무위키 각주처럼 메모를 페이지 위 위치에 묶는다.

| 종류 | 만드는 법 | 페이지 위 표시 | 각주 위치 |
|---|---|---|---|
| 밑줄 + 설명 | 텍스트 선택 → 액션 바 "밑줄+설명" 또는 ⇧⌘U | 밑줄 | 선택 끝 (위첨자) |
| 형광펜 | 액션 바 "하이라이트" (⇧⌘H), "메모" (⇧⌘M) | 형광펜 | 메모가 있을 때만, 선택 끝 |
| 영역 메모 | ⌥ 드래그로 사각형 지정 | 테두리 사각형 | 사각형 오른쪽 위 |
| 페이지 메모 | Claude 답 "메모로 저장", 텍스트 선택 없이 메모 추가 | 없음 | 페이지 하단 가운데 (여러 개면 나란히) |

- 번호는 **페이지마다 1부터**, 위에서 아래·왼쪽에서 오른쪽 순서. 페이지 메모가 맨 뒤.
- 마우스를 올리면 (0.18초 머문 뒤) 팝오버로 인용문과 설명을 보여준다. 누르면 편집 시트(색 변경, 삭제)를 연다.
- 각주는 PDF 위에 SwiftUI로 겹쳐 그리고, 스크롤·확대 때마다 화면에 보이는 페이지만 위치를 다시 계산한다. 페이지 색(읽기 테마)에 맞춘 배경을 쓴다.
- 스캔본처럼 글자를 선택할 수 없는 페이지는 영역 메모로 대신한다.

## 5. 단축키

| 키 | 동작 |
|---|---|
| ⌘O | 열기 |
| ⇧⌘1 / ⇧⌘2 | 첫 번째 템플릿(기본: 요약)을 현재 페이지 / 선택 영역에 실행 |
| ⌘. | Claude 중단 |
| ⇧⌘N | 새 대화 |
| ⇧⌘H | 선택 영역 하이라이트 |
| ⇧⌘U | 밑줄 긋고 설명 달기 |
| ⇧⌘M | 메모 추가 (선택 영역이 있으면 형광펜 + 인용, 없으면 페이지 메모) |
| ⇧⌘E | 메모를 Markdown으로 내보내기 |
| ⌘+ / ⌘- / ⌘0 | 확대 / 축소 / 화면에 맞추기 |
| ⌥⌘0 / ⌃⌘S | Claude 패널 / 사이드바 |

## 6. 검증 방법

클릭 없이 화면을 확인할 수 있도록 디버그 빌드(`scripts/bundle.sh debug`)에만 실행 인자 훅이 있다.

```sh
open -n build/DuckViewer.app --args book.pdf \
  -DVSidebar notes -DVSelect "2:webbed feet" -DVHighlight YES -DVFakeAI YES
```

| 인자 | 동작 |
|---|---|
| `-DVDataDir 경로` | 메모·대화 기록·컨텍스트 파일을 이 폴더에 저장 (실제 데이터를 건드리지 않도록 테스트할 때 항상 사용) |
| `-DVSidebar thumbnails\|outline\|notes\|search` | 사이드바 탭 |
| `-DVSelect "페이지:텍스트"` | 해당 페이지의 텍스트를 찾아 선택 (선택 액션 바 표시) |
| `-DVHighlight YES` | 선택 영역 하이라이트 |
| `-DVNote YES` | 메모 작성 시트 열기 |
| `-DVSearch 단어` | 문서 검색 |
| `-DVTheme sepia\|dark` | 읽기 테마 |
| `-DVChapter "목차 제목"` | 해당 장에 첫 번째 템플릿 실행 (실제 AI 호출) |
| `-DVRun 템플릿이름` | 선택 영역에 템플릿 실행 (실제 AI 호출) |
| `-DVUnderline "페이지:텍스트:설명"` | 밑줄 각주 만들기 (여러 개는 `|`로 구분) |
| `-DVArea "페이지:x,y,w,h:설명"` | 영역 메모 만들기 (PDF 좌표) |
| `-DVPageNote "설명"` | 현재 페이지에 페이지 메모 |
| `-DVGoToPage N` | N쪽으로 이동 |
| `-DVHover N` | 화면의 [N] 각주에 마우스를 올린 상태 |
| `-DVFakeAI YES` | 가짜 대화 (완료된 답 1개, 진행 중인 답 1개) |
| `-DVAsk "질문"` | 앞 요청이 끝난 뒤 현재 페이지에 대해 질문 (세션 이어가기 확인용, 실제 Claude 호출) |
