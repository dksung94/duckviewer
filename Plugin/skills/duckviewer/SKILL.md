# DuckViewer

사용자는 DuckViewer(macOS PDF 리더)에서 PDF를 읽으며 너와 대화한다. 이 스킬은 앱 기능 안내와, `duckviewer` 명령으로 앱을 직접 조작하는 방법을 담고 있다.

## 앱 기능 (사용자 안내용)

- 왼쪽 사이드바(⌃⌘S): 썸네일, 목차, 메모 목록, 검색 탭
- 텍스트를 드래그하면 선택 액션 바: 하이라이트(⇧⌘H), 밑줄+설명(⇧⌘U), 메모(⇧⌘M), 요약·쉽게 설명·번역, Claude에게 질문
- 메모는 나무위키 각주처럼 페이지 위에 [1], [2]로 붙는다. 번호는 페이지마다 1부터 위에서 아래 순서. 마우스를 올리면 내용이 뜨고, 누르면 편집 창(색 변경, 삭제)이 열린다.
  - 밑줄+설명: 밑줄 친 구절 끝에 각주
  - 형광펜: 노랑·초록·파랑·분홍. 메모를 달면 각주가 붙는다
  - 페이지 메모: 페이지 하단 가운데에 각주 (Claude 답의 "메모로 저장"도 이것)
  - 영역 메모: ⌥ 드래그로 사각형을 지정. 글자를 선택할 수 없는 스캔본용
- 목차 항목 우클릭 → 그 장 전체 요약·설명. 메모 Markdown 내보내기(⇧⌘E). 보기 메뉴: 확대/축소, 페이지 배치, 읽기 테마(기본·세피아·다크)
- 이 대화는 문서마다 저장되고 다시 열면 이어진다. Claude 패널 ⋯ 메뉴: 새 대화(⇧⌘N), 터미널에서 이어하기 명령 복사

## `duckviewer` 명령

Bash로 실행한다. 지금 열려 있는 문서에 바로 반영되고 결과는 JSON으로 나온다. 쪽 번호는 1부터.

| 명령 | 하는 일 |
|---|---|
| `duckviewer state` | 열린 문서, 현재 쪽, 총 쪽수, 선택한 텍스트 |
| `duckviewer notes --page N` | N쪽 메모 목록 (`--pages A-B`, `--all`도 가능). id, 각주 번호, 종류, 색, 인용문, 설명 |
| `duckviewer text --page N` | N쪽의 텍스트 (형광펜·밑줄을 칠할 글자를 고를 때) |
| `duckviewer highlight --page N --text "글자" [--color yellow\|green\|blue\|pink] [--note "설명"]` | 형광펜. 설명을 주면 각주가 붙는다 |
| `duckviewer underline --page N --text "글자" --note "설명"` | 밑줄 + 각주 |
| `duckviewer page-note --page N --note "내용"` | 페이지 하단 각주 (마크다운 가능) |
| `duckviewer edit --id ID [--note "새 설명"] [--color 색]` | 메모 수정 |
| `duckviewer delete --id ID [--id ID ...]` | 메모 삭제 (여러 개 가능) |
| `duckviewer goto --page N` | 그 쪽으로 이동 |

## 규칙

- 사용자가 바꾸라고 한 것만 바꾼다. 요청이 없으면 제안만 한다.
- `--text`는 그 쪽 텍스트에 있는 글자를 띄어쓰기·OCR 오류까지 그대로 복사한다. 앱이 그 글자를 찾아 표시한다. 한두 문장 이내로 짧게 고르고, 못 찾았다는 오류가 나면 `duckviewer text`로 확인한 뒤 더 짧게 다시 시도한다.
- 지우거나 고치기 전에 `duckviewer notes`로 현재 메모와 id를 확인한다. 중복 메모는 하나만 남기고 나머지를 지운다.
- 여러 개를 바꿀 때는 명령을 `&&`로 이어 한 번에 실행해도 된다.
- 끝나면 무엇을 했는지 짧게 알린다. 사용자는 Claude 패널에서 이번 답변이 한 일을 보고 되돌릴 수 있다.
